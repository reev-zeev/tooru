# Waslah Unified Platform

This repository is the rebuilt production platform for Waslah: a channel-agnostic logistics, mobility, delivery, merchant, enterprise, and operations platform designed for regional scale.

## Target geography
Gulf + Levant + Iraq + Turkey + Egypt + Yemen.

## Saudi commercial launch
Riyadh, Jeddah, Makkah, Taif, Madinah, Dammam.

## Architecture
Domain-first, application-centered, infrastructure-adaptable, channel-agnostic, horizontally scalable.

Legacy repositories are source material only. The final platform is rebuilt here deliberately; legacy projects are never nested inside this repository.

## Current phase
Foundation and production architecture.
